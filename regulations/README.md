# Catálogo regulatório da APeX-API

**Nenhuma regra entra em modo REGULATORY até aprovação fundamentada.**
Consulte a Seção 2 e a Seção 12 do [`plan.md`](../plan.md).

Para cadastrar uma regra: obter texto oficial vigente, conferir as alterações,
copiar `specifications/TEMPLATE.md`, documentar o cenário e os contraexemplos,
registrar vigência e fonte, adicionar testes independentes, solicitar revisão.

Não considerar o arquivo YAML em estado `DRAFT` como implementação válida.
